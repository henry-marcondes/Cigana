# 📚 Projeto Cigana

Sistema de **livro interativo** onde o usuário toma decisões que alteram o rumo da história.

---

## 🚀 Tecnologias utilizadas

- ⚙️ Backend: Node.js + Express
- 🗄️ Banco de Dados: PostgreSQL
- 🎨 Frontend: Next.js
- 🔗 API REST

---

## 🎮 Funcionalidades

- 📖 Cadastro de livros
- 🧩 Capítulos interativos
- 🔀 Sistema de escolhas (navegação dinâmica)
- 🔗 Integração frontend + backend
- 💾 Estrutura preparada para salvar progresso
