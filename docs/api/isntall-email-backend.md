# Criando o EmailService

## Brevo SMPT
** O Brevo possui plano gratuito, mas os limites e condições podem mudar **

> Plano gratuito atual
> US$ 0 por mês
> Sem cartão de crédito
> Sem prazo de expiração
> Até 300 e-mails por dia
> Inclui e-mails transacionais
> Permite uso via SMTP
> Os e-mails não utilizados não acumulam para o dia seguinte.
