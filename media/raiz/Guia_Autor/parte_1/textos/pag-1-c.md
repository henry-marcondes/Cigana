
## 3. Conheça seu perfil de Autor

O perfil reúne as informações utilizadas para identificar e apresentar o Autor na Plataforma.

Mantenha seus dados atualizados para facilitar a identificação e a comunicação relacionadas às suas atividades.

### 3.1. Informações de apresentação

Conforme os campos disponibilizados, o perfil pode incluir:

- Nome público;
- Biografia;
- Foto de apresentação.

Utilize a biografia para apresentar sua trajetória, seus interesses literários e outras informações relevantes para os leitores.

### 3.2. Dados cadastrais

Além das informações públicas, o Autor pode precisar completar seus dados cadastrais para atender aos requisitos administrativos da Plataforma.

Essas informações incluem:

- Dados pessoais;
- Identificação como pessoa física ou jurídica;
- Telefones;
- Endereços.

A pessoa física e a pessoa jurídica são modalidades que podem coexistir no cadastro, quando aplicável. A inclusão ou atualização de uma delas não deve ser interpretada como exclusão automática da outra.

### 3.3. Regularização cadastral

A regularização cadastral é uma responsabilidade do Autor.

Para manter seu cadastro atualizado:

1. Acesse a área de regularização cadastral.
2. Confira as informações existentes.
3. Preencha ou atualize os dados solicitados.
4. Verifique os telefones e endereços cadastrados.
5. Confira se há alguma pendência apresentada pela Plataforma.

Se houver uma pendência, siga as orientações correspondentes antes de prosseguir com as etapas que dependem de sua regularização.

**Importante:** a regularização cadastral e a construção de uma obra são atividades distintas. A aprovação para começar a desenvolver uma obra não deve ser confundida com a autorização para publicá-la.
